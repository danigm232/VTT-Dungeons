# Variantes sentadas de los personajes existentes

Recursos generados con la herramienta integrada ImageGen, modo edición con
referencia al sprite del personaje existente. Fondo transparente preservado.
No representan personajes nuevos: reutilizan identidad, colores y vestuario.

| Archivo | Personaje |
| --- | --- |
| wizard-seated.png | Mike: elfo rubio, ropa azul |
| cleric-seated.png | Mia: sprite existente de clérigo con barba rojiza y armadura |
| rogue-seated.png | Trinity: pelo oscuro, ropa de cuero y pieles |

Los tres PNG de 1254 × 1254 se usan como un único fotograma sit, con anclaje
inferior .94. La altura y posición se resuelven mediante el asiento del escenario.
Al moverse se recuperan las animaciones existentes de locomoción.

## Prompts utilizados

Variantes del mismo prompt de edición: «Usa el sprite adjunto como referencia
obligatoria de identidad y estilo HD-2D del personaje. Mantén rostro, cabello,
vestuario, colores, proporciones y calidad del sprite existente. Crea una pose
sentada de cuerpo entero, tres cuartos, mirando ligeramente hacia la cámara,
rodillas dobladas, manos reposando sobre las rodillas, sin armas en las manos,
sin silla, banco, suelo, sombra de fondo ni objetos adicionales. El asiento lo
proporciona el entorno 3D. Personaje completo, centrado, fondo realmente
transparente». Cada llamada identificó el personaje de la tabla como referencia.
