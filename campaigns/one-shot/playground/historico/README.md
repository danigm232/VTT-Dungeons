# Histórico de Babylon Playground

Aquí se guardan automáticamente las versiones anteriores del Playground de D8 Night.

La raíz de `campaigns/one-shot/playground/` conserva únicamente la versión actual, por ejemplo:

```text
playground_v6.json
```

Al publicar v7, v6 se mueve aquí como:

```text
historico/playground_v6.json
```
