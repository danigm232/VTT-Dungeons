# D8 Night · pendientes visuales tras la auditoría de acciones

Estado actualizado: 04/10/2026. La lógica y el catálogo de animaciones se comprueban mediante las pruebas de acciones/atlases; la aprobación artística y el hardware físico siguen pendientes. No confundir una animación disponible con una nueva capacidad del personaje.

- El catálogo integrado amplía acciones, marcha/carrera direccional y transiciones corporales de las fichas de D8. La cobertura, dimensiones y transparencia real se verifican en `d8-animation-completion.test.ts`. Algunos gestos se reutilizan de forma deliberada; no afirmar que todas las acciones tengan ilustración exclusiva. Revisar manualmente fluidez, silueta y encaje artístico.
- La vaca no recibe un perfil de combate inventado: el PDF de D8 Night no proporciona uno. Añadirlo cuando el DM elija una fuente o estadísticas concretas.
- Nube de niebla ya dispone de un área visual persistente de 6 m y hasta una hora, vinculada a concentración y conservada al guardar/restaurar. El efecto visual no concede por sí solo oscuridad, ocultación mecánica ni bloqueo automático de visión: esas consecuencias siguen guiadas por el DM. No confundirlo con las paredes que sí bloquean ataques.
- Remendar, Prestidigitación, Encontrar familiar, Disco flotante, Identificar, Caída de pluma y el encendido de objetos inflamables por Proyectil de fuego siguen siendo efectos guiados por el DM. Sus costes, objetivos, alcance y animación están representados; crear entidades persistentes para familiar/disco u objetos incendiados queda para otra fase.
